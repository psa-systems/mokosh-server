# mokosh-server / mokosh-apps YT ticket cleanup plan (2026-11-17)

Snapshot of every unresolved YouTrack issue across `PMS` (mokosh-server) and `MAPPS` (mokosh-apps), grouped by what kind of work it represents and in what order it is cheapest to clear. Each ticket listed under "immediately actionable" gets its own per-ticket file alongside this one as it starts.

## Guiding rule

One ticket, one branch, one PR. The branch name follows the repo convention (`fix/`, `feat/`, `chore/`, `docs/`) and carries the YT id. The commit body ends with `#<YT-ID>` on its own line. After push, the compare URL is handed back to the user to open the PR.
